# petshopJava

Descrição
---------
Projeto Java para gerenciar um pet shop (clientes, pets, agendamentos, produtos, etc.).

Principais tecnologias
---------------------
- Java (versão mínima recomendada: 11+)
- Build: Maven (pom.xml) 
- frameworks Spring Boot

Pré-requisitos
--------------
- JDK 11 ou superior instalado
- Maven 
- Banco de dados PostgreSQL

Estrutura típica do projeto
--------------------------
- src/main/java — código-fonte da aplicação
- src/main/resources — recursos (configurações, arquivos estáticos, templates)
- src/test/java — testes automatizados
- pom.xml / build.gradle — arquivo de build e dependências
